## 📱 唤起App机制

### 美团链接格式

当前生成的链接：
```
https://i.meituan.com/search?q=上海+晓燕生煎
https://i.meituan.com/hotel/search?q=上海+静安citigo欢阁酒店
```

### 工作原理

1. **移动端**：点击链接 → 自动唤起美团App → 直达搜索页
2. **桌面端**：点击链接 → 打开美团网页版

### 返现参数（审核通过后）

美团联盟审核通过后，链接会自动升级为：
```
https://i.meituan.com/search?q=xxx&actId=418&sid=001
```

- `actId`: 美团活动ID
- `sid`: 推广位ID
- 用户购买后，自动记录返现

### JavaScript渲染（app.js）

```javascript
// 识别美团链接，渲染为按钮
.replace(/\[([^\]]*?(?:美团|团购|预订)[^\]]*?)\]\(([^)]+meituan[^)]*)\)/gi, 
  function(match, text, url) {
    let icon = text.includes('预订') ? '🏨' : '🍽️';
    let type = text.includes('预订') ? '预订' : '团购';
    
    return `<a href="${url}" class="meituan-button">
      ${icon} ${type} <span class="cashback-badge">💰 有返现</span>
    </a>`;
  }
)
```

## 📞 问题排查

### Q1: 按钮没有显示？
**A**: 检查链接格式是否包含 `meituan`，只有美团链接会被渲染为按钮。

### Q2: 点击没有唤起App？
**A**: 
1. 确保手机安装了美团App
2. iOS可能需要点击"打开"确认
3. 部分浏览器（如微信）可能拦截，复制链接到Safari测试

### Q3: 样式错乱？
**A**: 
1. 强制刷新（Ctrl+F5 或 Cmd+Shift+R）
2. 清除浏览器缓存
3. 检查网络连接（Tailwind CSS从CDN加载）

### Q4: 返现标识不跳动？
**A**: 检查CSS动画是否加载：
```javascript
// 浏览器控制台测试
document.querySelector('.cashback-badge')
```

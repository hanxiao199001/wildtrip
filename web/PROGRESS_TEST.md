## ❌ 常见问题排查

### 问题1：WebSocket连接失败
```
控制台显示：WebSocket connection failed
```

**解决方法：**
1. 检查后端服务是否运行：
   ```bash
   ps aux | grep "python3.*app.py"
   ```
2. 检查端口5000是否开放：
   ```bash
   netstat -tuln | grep 5000
   ```
3. 检查防火墙规则

### 问题2：进度不更新
```
进度一直停在某个百分比
```

**解决方法：**
1. 打开控制台，看是否有报错
2. 检查后端日志：
   ```bash
   tail -50 /root/clawd/wildtrip/logs/backend.log
   ```
3. 重启后端服务：
   ```bash
   pkill -f "python3.*app.py"
   cd /root/clawd/wildtrip/backend
   nohup python3 app.py > ../logs/backend.log 2>&1 &
   ```

### 问题3：进度更新但不显示文字
```
只显示百分比，没有操作信息
```

**解决方法：**
1. 清除浏览器缓存并刷新（Ctrl+Shift+R）
2. 检查 app.js 是否更新到最新版本

### 问题4：AI生成时间太长
```
进度停在 30-65% 超过1分钟
```

**说明：**
- 这是正常现象！DeepSeek API 生成需要 30-60 秒
- 进度条会在这段时间内模拟更新（每2秒+5%）
- 如果超过 2 分钟，检查：
  1. AI_API_KEY 是否配置正确
  2. DeepSeek API 是否可用
  3. 网络连接是否正常

| 模式 | 预期时间 | 进度更新频率 |
|------|---------|-------------|
| 完整攻略 | 40-60秒 | 每2秒更新 |
| 只推酒店 | 25-35秒 | 每2秒更新 |
| 只推美食 | 25-35秒 | 每2秒更新 |

**进度更新节奏：**
- 0-15%：快速（准备阶段）
- 15-65%：模拟（AI生成中）
- 65-95%：快速（后处理）
- 95-100%：瞬间完成

### 1️⃣ FAQ 模块 + JSON-LD 结构化数据

**实现**：`backend/services/itinerary_generator.py`
- 新增 `_generate_faq_section()` 方法
- 新增 `_extract_faqs_from_content()` 智能提取逻辑
- 从攻略内容自动生成 5-8 个常见问题

**生成逻辑**：
- 根据 query 提取：天数、人群（亲子/孩子年龄）、预算、月份/季节
- 根据 content 提取：酒店名、海滩名、餐厅数量
- 自动生成符合上下文的 Q&A

**示例问题**：
```
Q: 海口二月份带7岁孩子去哪个海滩人少？
A: 西海岸后海角石滩，从市区开车约40分钟，退潮时段（约15:30-17:30）
   水深仅20-50cm，几乎无游客，适合学龄儿童赶海。
```

**JSON-LD 输出**：
```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [...]
}
```

**关键特性**：
- 答案必须包含**具体数字、地名、价格**（不泛泛而谈）
- 自动插入到 `<head>` 标签中
- HTML 部分显示在页面底部

**使用方法**：
```bash

  --skip-topics \\
```

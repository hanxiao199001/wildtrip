## 💻 使用方法

### 方法1：直接注入Prompt（立即可用）

```python
# 伪代码
def generate_sudongpo_route(query):
    # 1. 加载数据
    timeline = load_json("苏东坡/时间线.json")
    poems = load_json("诗词/苏东坡诗词库.json")
    places = load_json("地点/苏东坡路线地点.json")
    
    # 2. 组装Prompt
    prompt = f"""
    用户需求：{query}
    
    【历史背景】
    {timeline的核心事件}
    
    【诗词资料】
    {poems}
    
    【地点信息】
    {places}
    
    要求：
    1. 严格基于史料，标注出处
    2. 每个地点都讲"为什么来""发生了什么""留下什么诗"
    3. 设计现代体验（朗诵/美食/沉思）
    """
    
    return AI_generate(prompt)
```

## 💡 关键洞察

### 1. 历史数据是野游记的护城河

**为什么？**
- ❌ 马蜂窝、小红书：景点介绍 + 网红打卡
- ✅ 野游记：历史还原 + 诗词现场 + 哲学沉思

**壁垒：**
- 竞品做不了（没有历史数据积累）
- 用户走不了（深度体验无可替代）

---

### 2. 数据质量 > 数据量

**当前：** 1个人物（苏东坡）深挖  
**未来：** 50个人物浅挖 ❌

**正确路径：**
- 先做好3-5个人物（苏轼、玄奘、李白、徐霞客、红军长征）
- 深度 > 广度
- 每个都能让用户"哇，原来历史可以这么玩"

---

### 3. 用户不是来上历史课

**错误示范：**
"公元1082年7月16日，苏轼作《念奴娇·赤壁怀古》一首，词中..."（教科书）

**正确示范：**
"1082年某个月圆之夜，苏东坡和朋友泛舟赤壁矶，江水汤汤，明月皎皎...你可以在赤壁公园租船，学他'泛舟赤壁'，在船上朗诵《念奴娇》，感受'大江东去'的豪迈。"（旅游体验）

# 🚀 野游记 WildTrip - 快速开始

## 后端启动（5分钟）

### 1. 进入后端目录
```bash
cd /root/clawd/wildtrip/backend
```

### 2. 配置环境变量
```bash
cp .env.example .env
nano .env  # 编辑配置文件
```

**必填配置：**
```env
# 如果有DeepSeek API Key
AI_API_KEY=sk-your-key-here
AI_BASE_URL=https://api.deepseek.com
AI_MODEL=deepseek-chat

# 如果没有API Key，留空使用Mock数据
AI_API_KEY=
```

**美团联盟配置（审核通过后填写）：**
```env
MEITUAN_ACT_ID=your_act_id_here
MEITUAN_SID=your_sid_here
```

### 3. 启动服务
```bash
./start.sh
```

**或手动启动：**
```bash
pip install -r requirements.txt
python app.py
```

### 4. 测试接口
```bash
# 健康检查
curl http://localhost:5000/api/health

# 创建生成任务
curl -X POST http://localhost:5000/api/generate \
  -H "Content-Type: application/json" \
  -d '{"query":"海口3天游","mode":"full"}'
```

## 常见问题

### Q: 没有API Key怎么办？
**A:** 不影响开发！系统会自动使用Mock数据，可以正常测试流程。

### Q: 美团联盟链接怎么配置？
**A:** 审核通过前，系统使用搜索链接（可点击但无返佣）。审核通过后，在.env填写配置即可自动切换。

### Q: 生成速度慢怎么办？
**A:** 
- 使用DeepSeek比OpenAI快3-5倍
- 模式选`hotel`或`food`更快（20秒内）
- 优化prompt减少生成内容

## 生产部署

### 1. 使用gunicorn（推荐）
```bash
pip install gunicorn eventlet
gunicorn --worker-class eventlet -w 1 app:app -b 0.0.0.0:5000
```

### 2. 使用systemd
创建 `/etc/systemd/system/wildtrip.service`:
```ini
[Unit]
Description=WildTrip Backend
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/clawd/wildtrip/backend
Environment="PATH=/usr/bin"
ExecStart=/usr/bin/python3 app.py
Restart=always

[Install]
WantedBy=multi-user.target
```

启动：
```bash
systemctl daemon-reload
systemctl start wildtrip
systemctl enable wildtrip
```

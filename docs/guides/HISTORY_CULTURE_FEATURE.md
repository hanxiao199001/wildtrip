## 📖 Prompt设计精华

### 核心结构
```
# 历史背景（公元XXX年，发生了什么）
# 核心主题（诗词/美食/哲学/古今对比）
# 路线设计（每一站都讲故事）
## 第X站：地点
  - 历史坐标：公元XXX年，XX发生了XX
  - 核心事件：详细叙述
  - 今日体验：现代游客可以做什么
  - 诗词共鸣：引用原文

# 金句收尾（升华主题）
```

### 文风要求
- ✅ 不说"网红打卡"，说"东坡足迹"
- ✅ 不说"景点推荐"，说"诗词现场"
- ✅ 每个地方都讲"为什么来""发生了什么""留下什么诗"
- ✅ 像个有文化的野导游，不是历史老师

### 金句示例
> "走完苏东坡被贬之路，你会明白：
> 人生的低谷，往往是灵魂的高峰。
> 他被贬得越远，诗写得越好；
> 处境越艰难，心境越豁达。
> 这才是真正的'野路子'——
> 不是躲避苦难，而是把苦难活成诗。"

### 用户输入示例

### 生成流程
1. 用户选择"📜 历史人文"模式
2. 输入人物名或路线
3. AI 自动识别人物（苏东坡/玄奘/李白）
4. 使用对应的历史人文 Prompt 生成
5. 输出诗词+故事+美食+景点的深度攻略

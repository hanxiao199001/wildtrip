# 💡 美团搜索提示优化方案

## 🔴 问题回顾

用户反馈：点击美团链接后跳转到**美团公司介绍页**（www.meituan.com），对用户没有任何帮助。

**之前尝试的方案都失败了：**
1. ❌ `meishi.meituan.com/s/{关键词}` → 403 Forbidden
2. ❌ `i.meituan.com/search?q={关键词}` → 跳转到首页，不触发搜索
3. ❌ `www.meituan.com/s/{关键词}` → "出错了，我迷路了"
4. ❌ `www.meituan.com` → 公司介绍页（用户反馈的问题）

**根本原因：**
- 美团有严格的**防盗链保护**
- 外部网站无法直接触发美团搜索
- 需要**美团联盟审核通过**才能拿到真实推广链接

---

## ✅ 最终解决方案

**核心思路：** 既然无法跳转，就**不跳转了** - 直接显示搜索关键词，让用户手动复制到美团App

### 用户体验流程

```
1. 用户看到攻略中的推荐：
   ┌─────────────────────────────────────┐
   │ **海南粉老店** ¥15/人 ⭐4.8        │
   │ - 特色：海南粉、清补凉             │
   │ - 🍽️ 美团搜索：海南粉老店          │
   │   👆点击复制                       │
   └─────────────────────────────────────┘

2. 用户点击黄色框：
   ┌─────────────────────────────────────┐
   │ 🍽️ 美团搜索：海南粉老店 ✅已复制   │  ← 背景变绿2秒
   └─────────────────────────────────────┘
   
3. 关键词「海南粉老店」自动复制到剪贴板

4. 用户打开美团App：
   - 点击搜索框
   - 长按粘贴「海南粉老店」
   - 搜索并购买
```

## 🛠️ 技术实现

### 后端（services/affiliate.py）

```python
def get_search_link(self, query: str, category: str = "all") -> str:
    # 清理关键词（去掉城市名，只保留商家名）
    clean_query = query.split()[-1] if ' ' in query else query
    
    # 返回特殊格式，前端会识别
    return f"SEARCH_HINT:{clean_query}"
```

**示例：**
```
输入: "海口 海南粉老店"
输出: "SEARCH_HINT:海南粉老店"
```

---

### 前端（web/app.js）

**1. 识别SEARCH_HINT格式**
```javascript
.replace(/\[([^\]]*?(?:美团|团购|预订|门票)[^\]]*?)\]\(SEARCH_HINT:([^)]+)\)/gi, 
    function(match, text, keyword) {
        // 渲染为可点击复制的提示框
        return `<span class="meituan-search-hint" 
                      onclick="copyToClipboard('${keyword}', this)">
            ${icon} <strong>美团搜索：${keyword}</strong> 
            <span>👆点击复制</span>
        </span>`;
    }
)
```

**2. 复制关键词**
```javascript
function copyToClipboard(keyword, element) {
    // 复制到剪贴板
    navigator.clipboard.writeText(keyword).then(() => {
        // 修改提示文字
        element.innerHTML = element.innerHTML.replace('👆点击复制', '✅已复制');
        element.style.background = 'linear-gradient(135deg, #4CAF50 0%, #66BB6A 100%)';
        element.style.color = '#fff';
        
        // 2秒后恢复
        setTimeout(() => {
            element.innerHTML = originalHTML;
            element.style.background = '';
            element.style.color = '';
        }, 2000);
    });
}
```

## 📝 技术细节总结

### 数据流

```
AI生成攻略
  ↓
包含 [美团团购](LINK_FOOD_海南粉老店)
  ↓
后端替换 LINK_FOOD_海南粉老店
  ↓
生成 SEARCH_HINT:海南粉老店
  ↓
前端检测 SEARCH_HINT: 格式
  ↓
渲染为可点击的搜索提示框
  ↓
用户点击 → 复制关键词
```

### 关键文件

**1. 后端**
- `backend/services/affiliate.py` - 生成SEARCH_HINT格式
- `backend/api/generate.py` - 替换LINK_格式为SEARCH_HINT

**2. 前端**
- `web/app.js` - 检测SEARCH_HINT，渲染为搜索提示
- `web/index.html` - 添加.meituan-search-hint样式

**3. Prompt**
- `backend/prompts/wildtrip_prompt.py` - 要求AI生成LINK_格式

## 🚀 优化方案

### 1️⃣ 生成速度优化

#### 当前问题分析:
- AI 调用超时设置 120秒,太长
- RAG 检索可能拖慢速度
- prompt 太复杂导致生成慢

#### 解决方案:

**A. 并行处理 (最重要)**
```python
# 当前:串行生成
攻略生成 → 酒店推荐 → 美食推荐 → 门票推荐  (总计 60秒)

# 优化后:并行生成
攻略生成 (30秒)
    ↓
并发执行:
  ├─ 酒店推荐 (10秒)
  ├─ 美食推荐 (10秒)  
  └─ 门票推荐 (10秒)
总计: 30秒 + 10秒 = 40秒 (节省33%)
```

**B. 使用更快的模型**
```python
# 当前: deepseek-chat (速度中等)
# 优化: deepseek-chat (保持) + 流式输出

# 环境变量优化:
AI_MODEL=deepseek-chat  # 或 gpt-4o-mini (更快)
AI_TIMEOUT=60  # 从120秒降到60秒
```

**C. 简化 Prompt**
```python
# 当前 prompt 可能太详细
# 优化: 分离核心信息和扩展信息
# 第一阶段:生成核心框架(快)
# 第二阶段:填充细节(慢,可后台)
```

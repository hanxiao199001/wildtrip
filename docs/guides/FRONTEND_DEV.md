## 🐛 常见问题

### 1. 小程序请求失败

**问题：** `request:fail url not in domain list`

**解决：**
- 开发者工具 → 详情 → 本地设置 → 勾选「不校验合法域名」
- 或者在微信公众平台配置服务器域名白名单

---

### 2. 后端服务未响应

**检查：**
```bash
# 检查服务是否运行
ps aux | grep "python.*wildtrip"

# 检查端口是否监听
lsof -i :5000

# 查看日志
cd /root/clawd/wildtrip/backend
tail -50 logs/server.log
```

**重启：**
```bash
cd /root/clawd/wildtrip/backend
screen -r wildtrip-backend
# Ctrl+C 停止
python3 app.py
```

---

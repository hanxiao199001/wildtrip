# 小程序订阅消息申请指南

## 📋 申请步骤

### 1. 登录微信公众平台

访问: https://mp.weixin.qq.com

选择你的**小程序**账号登录

---

### 2. 进入订阅消息管理

导航路径:
```
功能 → 订阅消息
```

或直接访问:
```
https://mp.weixin.qq.com/wxamp/newtmpl/mytmpl?token=YOUR_TOKEN
```

---

### 3. 选择模板

点击 **"选用"** → 选择模板类型

#### 推荐模板类别:
- **旅游服务** → "行程提醒"
- **生活服务** → "内容更新提醒"
- **工具** → "待办事项提醒"

#### 搜索关键词:
```
"行程提醒"
"旅游计划"
"出游提醒"
```

---

### 4. 模板内容示例

**模板标题:** 行程提醒

**模板内容:**
```
{{thing1.DATA}}  ← 目的地
{{date2.DATA}}   ← 出行时间
{{thing3.DATA}}  ← 行程安排
{{thing4.DATA}}  ← 温馨提示
```

**字段说明:**
- `thing1` - 短文本(20字以内) - 目的地名称
- `date2` - 日期 - 出行时间
- `thing3` - 短文本(20字以内) - 行程亮点
- `thing4` - 短文本(20字以内) - 温馨提示

---

### 5. 提交审核

填写:
- **模板用途:** 为用户推送周末出游计划
- **使用场景:** 用户订阅后,每周四推送周末旅游推荐

审核时间: **1-2 个工作日**

---

### 6. 获取模板 ID

审核通过后,在列表中找到模板,复制 **模板 ID**

格式类似:
```
xxxxxxxxxxxxxxxxxxxxx (一串字母数字)
```

**保存这个 ID,后续代码会用到!**

---

## 🎯 野游记推荐配置

### 建议申请 2 个模板:

#### 模板 1: 周末计划推送
```
标题: 周末出游提醒

{{thing1.DATA}} - 推荐目的地
{{date2.DATA}} - 出行日期
{{thing3.DATA}} - 行程亮点
{{thing4.DATA}} - 温馨提示

用途: 每周四推送周末计划
```

#### 模板 2: 价格变动提醒(可选)
```
标题: 价格变动通知

{{thing1.DATA}} - 酒店名称
{{amount2.DATA}} - 当前价格
{{thing3.DATA}} - 价格趋势
{{thing4.DATA}} - 预订建议

用途: 酒店价格降价时提醒用户
```

## 📝 申请时的注意事项

### ✅ 容易通过的理由

- "为订阅用户推送个性化旅游推荐"
- "基于用户偏好生成周末出游计划"
- "提醒用户查看已生成的行程"

### ❌ 容易被拒的理由

- "推送营销广告"
- "促销活动通知"
- "优惠券发放"

---

## 🔧 配置到代码

审核通过后,将模板 ID 配置到环境变量:

```bash
# .env
WECHAT_SUBSCRIBE_TEMPLATE_WEEKEND=你的模板ID
WECHAT_SUBSCRIBE_TEMPLATE_PRICE=你的模板ID(可选)
```

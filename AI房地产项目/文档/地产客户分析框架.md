# 🏠 地产客户数据分析框架

> **目标**：通过AI分析客户数据，帮助销售团队提升80套未售房源的转化率

---

## 📋 数据需求清单

### 1. 成交客户记录（最近1年）
- 客户基本信息
  - 年龄 / 年龄段
  - 职业 / 收入水平
  - 家庭结构（单身/已婚/有孩子）
  - 购房目的（自住/投资/改善）
- 购买信息
  - 买的哪套房（户型、楼层、朝向、面积、价格）
  - 最终成交价（折扣情况）
  - 付款方式（全款/贷款）
- 转化过程
  - 客户来源渠道（线上/线下/老带新）
  - 首次来访时间 → 成交时间（转化周期）
  - 来访次数
  - **负责的销售员姓名/ID** ⚠️ 重要
  - 销售备注（沟通记录、客户顾虑、成交关键点）

### 2. 未成交客户记录（最近1年）
- 客户基本信息（同上）
- 意向信息
  - 看过哪些房型
  - 预算范围
  - 关注的重点（地段/学区/价格/户型）
- 流失原因
  - 为什么没买（价格/户型/地段/竞品/其他）
  - 销售备注（"老婆不同意"、"再考虑"、"嫌贵"这类原始记录）
  - **负责的销售员姓名/ID** ⚠️ 重要
  - 最后接触时间

### 3. 80套未售房源清单
- 基本信息
  - 楼栋号、单元、门牌号
  - 户型（几室几厅）
  - 面积
  - 楼层 / 总楼层
  - 朝向
  - 价格（总价 + 单价）
  - 装修情况
- 滞销分析（如果有的话）
  - 挂牌多久了
  - 降价记录
  - 内部分析的滞销原因

### 4. 销售员信息
- 销售员姓名/ID
- 入职时间 / 经验
- 负责客户数量
- 成交数量 + 成交率

## 🎯 三层分析结构

### 第一层：客户画像分析

**目的**：找出"高转化客户"的特征

**分析维度**：
1. 人口统计学特征
   - 年龄段分布（成交 vs 未成交）
   - 职业类型（公务员/企业主/白领/其他）
   - 家庭结构（单身/夫妻/三口之家/三代同堂）

2. 购房特征
   - 预算范围
   - 购房目的（自住/投资）
   - 首付能力（全款/高首付/低首付）

3. 行为特征
   - 来访次数（1次/2-3次/4次以上）
   - 决策周期（1周内/1个月内/3个月以上）
   - 客户来源（线上广告/门店/老带新/其他）

**输出**：
- 成交客户 Top 3 特征组合
- 未成交客户 Top 3 流失原因
- 高价值客户画像定义

**示例输出**：
```
✅ 高转化客户画像
- 年龄：30-40岁
- 职业：企业管理层/个体经营者
- 家庭：已婚有孩，准备改善住房
- 预算：150-200万
- 行为：来访2-3次，决策周期1个月内
- 关注点：学区 > 户型 > 价格

❌ 高流失客户画像  
- 年龄：25-30岁
- 职业：普通白领
- 家庭：新婚/备孕
- 预算：100-120万（预算紧张）
- 行为：来访1次，犹豫期长
- 流失原因：价格高于预算、老婆/父母不同意、竞品更便宜
```

---

### 第二层：转化漏斗 + 流失分析

**漏斗阶段**：
```
首次到访 → 多次来访 → 意向明确 → 成交
  100%       40%         20%        10%
```

**每个阶段的分析**：

1. **首次到访 → 多次来访**
   - 流失率：60%
   - 主要原因：价格、位置、户型不满意
   - AI提取备注关键词：统计"太贵"、"地段不好"、"户型不喜欢"出现频率

2. **多次来访 → 意向明确**
   - 流失率：50%
   - 主要原因：对比竞品、家人反对
   - AI提取备注关键词：统计"隔壁XX楼盘更便宜"、"老婆不同意"、"父母不满意"

3. **意向明确 → 成交**
   - 流失率：50%
   - 主要原因：贷款/首付问题、最后一刻改变主意
   - AI提取备注关键词：统计"贷款批不下来"、"又去看了竞品"

**输出**：
- 转化漏斗可视化图表
- 各阶段流失原因分布（饼图/柱状图）
- 改进建议

---

### 第三层：房源匹配 + 销售员效能

#### A. 房源-客户智能匹配

**目标**：80套房 × 未成交客户池 → 找出最有可能成交的配对

**匹配逻辑**：
1. 预算匹配：客户预算 ± 10% = 房源价格
2. 户型匹配：客户需求（3室 → 优先推荐3室）
3. 特征匹配：客户画像 vs 已成交客户画像（相似度计算）

**输出**：
```
房源A（3室2厅，120㎡，180万，18楼）
  → 匹配客户：张三（预算170-190万，3口之家，喜欢高楼层）
  → 转化概率：85%
  → 建议话术：强调采光好、视野开阔、学区房

房源B（2室1厅，80㎡，110万，6楼）
  → 匹配客户：李四（预算100-120万，新婚夫妻，首次购房）
  → 转化概率：70%
  → 建议话术：强调总价低、首付压力小、性价比高
```

#### B. 销售员效能分析

**目的**：找出Top销售员的差异化打法

**分析维度**：
1. 转化率对比
   - 销售员A：转化率40%（10个客户成交4个）
   - 销售员B：转化率10%（10个客户成交1个）

2. 客户画像对比
   - 同样是"30-40岁，预算150-200万"的客户
   - A销售员成交率40%，B销售员成交率10%
   - 差异在哪？

3. 沟通策略提取（从备注中AI分析）
   - Top销售员常用话术
   - 处理异议的方法
   - 跟进频率和节奏

**输出**：
- 销售员排行榜（转化率、平均成交周期、客单价）
- Top销售员的"成功模式"总结
- 低转化销售员的问题诊断
- 客户分配优化建议（高价值客户 → 高转化销售员）

## 🛠️ 技术实现

### 工具栈
- **数据处理**：Python + Pandas（清洗、转换）
- **AI分析**：DeepSeek / Claude（从备注中提取结构化信息）
- **可视化**：Matplotlib / Plotly（图表生成）
- **报告生成**：Markdown → PDF / PPT

### 核心能力展示
**最大的价值不是分析结论，而是"把脏数据变成决策依据"的过程**

销售备注：
```
"客户说再考虑"
"老婆不同意"
"嫌贵了"
"隔壁XX楼盘更便宜"
```

↓ AI提取结构化信息 ↓

```json
{
  "流失原因": "家人反对",
  "核心顾虑": "价格高于预期",
  "竞品对比": "XX楼盘",
  "决策阶段": "意向明确但未成交"
}
```

这个能力本身就是产品卖点。

## 🎯 项目定位

**产品名称：** 野游记 WildTrip  
**新Slogan：** 懒人旅游AI，预订返现50%  
**定位：** 快速攻略生成 + 返现导购平台

**核心价值（vs 马蜂窝）：**
- 🚀 **速度快** - 30秒出结果（vs 马蜂窝5分钟多轮对话）
- 😴 **懒人友好** - 一句话搞定（vs 需要选4-5个选项）
- 💰 **返现省钱** - 50%返佣给用户（vs 马蜂窝不返现）

**差异化策略：**
- 不和马蜂窝正面竞争
- 做细分市场：临时决策 + 追求效率 + 想省钱的用户

## 📊 商业模式（返现模式）

### Phase 1：激进返现策略（0-6月）
```
用户搜索 → AI生成攻略（30秒） → 推荐酒店/餐饮/门票 
→ 跳转美团预订 → 返佣2-8% → 50%返给用户
```

**返现案例（海口3天游）：**
| 项目 | 消费 | 返佣率 | 总返佣 | 返给用户 | 我们收入 |
|------|------|--------|--------|----------|----------|
| 酒店 | ¥600 | 5% | ¥30 | ¥15 | ¥15 |
| 餐饮 | ¥300 | 8% | ¥24 | ¥12 | ¥12 |
| 门票 | ¥200 | 10% | ¥20 | ¥10 | ¥10 |
| **合计** | **¥1100** | - | **¥74** | **¥37** | **¥37** |

**用户视角：** 省了¥37（1.85%）  
**我们收入：** ¥37/用户

**vs 马蜂窝：**
- 马蜂窝：用户省¥0，平台赚¥74
- 野游记：用户省¥37，平台赚¥37（双赢！）

**目标：**
- 月活1000人 × 10%转化 = 100单
- 月收入：100 × ¥37 = ¥3700
- 用户口碑：真的省钱！

### Phase 2：商家直连（6-12月）
- 酒店联盟，低佣金3%
- 月GMV 100万
- 月收入3万

### Phase 3：平台化（12-24月）
- 扩展全品类
- 会员体系
- 月收入30万+
